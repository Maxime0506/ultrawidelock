UWB subsystem

Secure ranging

How the lock turns a time-of-flight measurement into an access decision, and what it refuses to do.

Session lifecycle

A ranging session is opened by the BLE layer once a credential verifies, never by the radio itself. uwl_sts_session_open() derives the STS key from the BLE handshake transcript, so a session cannot be reused across unlocks or across devices.

careful

Opening a session before credential verification is a distance-fraud hole: an attacker gets a keyed ranging channel for free. The facade asserts on this in debug builds.

Opening a session

uwb/sts_session.hview source
#include <uwl/sts_session.h>

int open_after_auth(const uwl_transcript_t *tr)
{
    uwl_sts_session_cfg_t cfg = {
        .channel   = 9,
        .rate_hz   = 10,
        .bound_cm  = 120,
        .integrity = UWL_RANGE_INTEGRITY_STRICT,
    };

    /* key material never leaves the key store */
    if (uwl_sts_derive(tr, &cfg.key) != 0)
        return -EACCES;

    return uwl_sts_session_open(&cfg);
}

Range integrity

Strict integrity runs three gates on every measurement. A single failing gate drops the measurement; three consecutive failures close the session and log to the flight recorder.

GateRejectsTunable
cir_leading_edgerelayed frames with a smeared first pathcir_thresh
rssi_vs_tofamplified replays at implausible powerrssi_window
rate_monotonicinjected frames out of the round schedule—
verified

The three gates are exercised on real silicon in tests/range_integrity and replayed in the digital twin against captured attack traces.
